# 权限能力边界清单

> 需要时 `@read_file skills/03_cap_system__v2.md` 查询，不占 prompt。
> 权限等级：默认 → su → su+ 递进

---

## 一、内置工具一览（共 14 个）

### 📖 读取类（默认可用，AI 可自动调用）

| 工具 | 说明 |
|------|------|
| `@read_file` | 读取文件内容（支持 tail/lines/offset） |
| `@scan_dir` | 扫描目录结构 |
| `@path_info` | 获取路径详细信息 |
| `@find` | 按文件名或内容搜索文件 |
| `@grep_symbol` | AST 搜索 Python 符号 |
| `@paste` | 读取剪贴板内容 |

### 🔍 搜索类（默认可用，AI 可自动调用）

| 工具 | 说明 |
|------|------|
| `@search` | 网页搜索（metaso/tavily/jina/bocha） |
| `@local_search` | 本地搜索（免费，多源聚合+缓存） |

### ✍️ 写入类（需 `/su` + 用户确认）

| 工具 | 说明 |
|------|------|
| `@write_file` | 创建/覆盖写入文件 |
| `@replace` | 局部替换文件内容（old→new） |
| `@create_dir` | 创建目录（含父目录） |
| `@delete` | 删除文件或目录 |
| `@rename` | 移动/重命名文件或目录 |

### ⚡ 执行类（需 `/su`）

| 工具 | 说明 |
|------|------|
| `@run_python` | 沙箱内执行 Python（su: 300s, su+: 无限制） |

## 二、权限分级

### 🟢 默认 — 沙箱只读

> 未提权时的初始状态，仅文件读取和搜索，不可执行代码。

| 能力 | 说明 |
|------|------|
| 📂 **读文件** | 白名单路径下读取 |
| 🔍 **搜索** | 搜索网页、本地搜索 |
| 📋 **剪贴板** | 读取剪贴板 |
| ❌ **写文件** | 拦截，提示提权 |
| ❌ **run_python** | 拦截，提示提权 |

### 🟡 su — 中级提权

> 解锁沙箱内 Python 执行 + 受限文件写入。AST 预检拦截危险操作。

| 能力 | 说明 |
|------|------|
| 📝 **写文件** | 白名单路径下写入，需确认 |
| 🐍 **run_python** | 沙箱内跑 Python，300s 超时，AST 预检拦截 `__subclasses__` 等逃逸 |
| 💻 **__exec__** | 白名单命令（ls/cat/grep/find/git/touch/mv/cp/rm 等），300s 超时，路径受沙箱检查 |
| 🔗 **网络** | 可调外部 API |
| ❌ **任意命令** | 拦截，仅白名单命令可执行 |

### 🔴 su+ — 完全放行

> 无 AST 拦截、完整 builtins、subprocess 任意命令、任意路径读写。
> 项目目录硬保护仍生效（`_PROTECTED_ROOT`）。

| 能力 | 说明 |
|------|------|
| 🔓 **任意命令** | subprocess 无限制 |
| 📂 **任意路径** | 读写任意路径（项目目录硬保护仍生效） |
| 🐍 **完整 Python** | 完整 builtins，含 `open`、`__import__` |
| ⏱ **run_python 无超时** | Python 执行不限时 |
| ⏱ **__exec__ 无超时** | shell 命令同样不限时 |

## 三、提权路径图

```
┌─────────────────────────────────┐
│      默认（只读沙箱）           │
│  read_file · search · paste     │
│   ❌ 写文件 · ❌ run_python      │
└──────────┬──────────────────────┘
           │ /su
           ▼
┌─────────────────────────────────┐
│      su（中级提权）              │
│  run_python(AST预检) · __exec__  │
│  (白名单) · 写文件(需确认)       │
└──────────┬──────────────────────┘
           │ /su+
           ▼
┌─────────────────────────────────┐
│      su+（完全放行）             │
│  任意命令 · 完整Python           │
│  任意路径(项目保护仍生效)        │
└─────────────────────────────────┘
```

## 四、场景速查

| 想干啥 | 最低权限 | 方式 |
|-------|---------|------|
| 读文件 | 默认 | `@read_file` |
| 搜目录结构 | 默认 | `@scan_dir` |
| 按名/内容搜文件 | 默认 | `@find` |
| 搜索网页 | 默认 | `@search` |
| 读剪贴板 | 默认 | `@paste` |
| 写文件 | su | `@write_file`（需确认） |
| 替换文件内容 | su | `@replace`（需确认） |
| 创建目录 | su | `@create_dir` |
| 删除文件 | su | `@delete`（需确认） |
| 重命名/移动 | su | `@rename`（需确认） |
| 跑 Python | su | `@run_python` |
| 执行 shell 命令 | su | `__exec__('ls -la')` |
| 任意命令 | su+ | `__exec__` 或 `subprocess.run` |
| 完整 Python | su+ | `@run_python`（无 AST 拦截） |

## 五、安全机制

| 机制 | 说明 |
|------|------|
| **路径白名单** | 只允许操作白名单目录下的文件 |
| **项目硬保护** | 项目代码目录始终只读（`_PROTECTED_ROOT`），`/su+` 也无法绕过 |
| **AST 预检** | su 级别拦截 `__subclasses__`、`__bases__` 等逃逸属性 |
| **审计引擎** | 序列模式匹配，19 条规则，记录/弹窗 |
| **文件配额** | 写入次数追踪，防滥用 |
| **紧急备份** | high 级告警自动触发 tar.gz 备份 |
